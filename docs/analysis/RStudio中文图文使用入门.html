RStudio 中文图文使用入门

这是一份先能看懂界面的教程：RStudio 本体仍是英文 UI，下面用中文解释每个区域做什么、怎么开始写 R 代码、怎么看数据、怎么出图、怎么生成报告。

先把两个误会说清楚

1. RStudio 没有被真正汉化

你看到的 File、Edit、Console、Environment 等仍是英文，这是 RStudio 本体界面。Console 里的中文只是 R 运行环境输出，不等于 IDE 已汉化。

2. 截图不全来自屏幕缩放

本机 RStudio 窗口 DPI 是 192，也就是 Windows 缩放约 200%。普通截图会只拿到逻辑尺寸 1280x720，DPI-aware 截图才能拿到完整 2560x1440 画面。

RStudio 主界面怎么看

RStudio 通常分成四块：左上 Source 写脚本，左下 Console 执行命令，右上 Environment 看变量和历史，右下 Files/Plots/Packages/Help/Viewer 看文件、图表、包、帮助和网页预览。

完整 DPI-aware 截图：右上是 Environment，右下是 Files，左侧是 Console。当前项目是 rstudio使用教程样例。
英文区域 中文理解 主要用途
Source 脚本编辑器 写 .R、.qmd、.Rmd 文件；点击 Run 运行当前行或选中代码。
Console 命令行 直接输入 R 命令，看运行结果和报错。初学者最常用。
Environment 工作区变量 显示当前创建的数据框、向量、模型等对象。
Files 项目文件 打开脚本、数据、报告；新建文件夹；删除/重命名文件。
Plots 图表窗口 显示 plot()、ggplot 等生成的图。
Packages R 包管理 安装、更新、加载 R 包。
Help 帮助文档 查函数用法，例如 ?plot。
Viewer 预览窗口 预览 HTML、Shiny、Quarto 输出。

第一步：打开或新建项目

  1. 点击菜单 File。
  2. 已有项目选 Open Project...；新项目选 New Project...。
  3. 看到右上角项目名后，说明当前工作目录已经切到这个项目。
建议以后都用 .Rproj 打开项目。这样数据、脚本、报告都在同一个目录，路径不容易乱。

第二步：写脚本并运行

打开 analysis.R 后，左上就是 Source。脚本里定义了一个 sales 数据框，然后打印数据并画图。

Source 面板里可以写 R 脚本；右上角的 Run 按钮用于运行当前行或选中的代码。
  1. 把光标放在某一行，点击 Run，只运行这一行。
  2. 选中多行后点击 Run，运行选中代码。
  3. 也可以在 Console 输入 source("analysis.R")，一次运行整个脚本。
如果运行后右上角 Environment 还是空的，通常是脚本没有真正跑到创建对象的那几行，或者焦点还停在别的软件窗口。

第三步：看变量、数据和图

你想做什么 点哪里 常用命令
看当前有哪些对象 右上 Environment ls()
查看数据表 Environment 中点数据框名字 View(sales)
看前几行 Console head(sales)
出图 右下 Plots plot(sales$users, sales$revenue)
查函数帮助 右下 Help ?plot

第四步：生成 Quarto 报告

本演示项目里有 report.qmd。这是 Quarto 报告文件，适合把代码、文字、图表放在一起，生成 HTML/PDF/Word。

  1. 在右下 Files 里点击 report.qmd。
  2. 打开后，Source 顶部通常会出现 Render 按钮。
  3. 点击 Render，生成 HTML 报告。
  4. 输出结果一般会在 Viewer 或文件目录里出现。

常用菜单中文速查
